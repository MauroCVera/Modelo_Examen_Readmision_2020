Modelo de Examen de Readmisión - UBA Derecho

Este proyecto es una simulación interactiva del Examen de Readmisión (Tema A) para la Facultad de Derecho de la Universidad de Buenos Aires (UBA), diseñado con los colores y estilo de la agrupación Nuevo Derecho.

🚀 Características

Evaluación Automatizada: Utiliza la API de Gemini (IA) para corregir tanto preguntas múltiple choice como casos prácticos a desarrollar (Derecho Penal), priorizando el razonamiento lógico.

Panel de Administración: Acceso seguro para autoridades del tribunal (Contraseña: MGWZ2020) para visualizar métricas, revisar exámenes y habilitar nuevos intentos.

Autenticación y Base de Datos: Integración nativa con Firebase Firestore para registrar alumnos e intentos de forma segura.

Diseño Responsivo: Interfaz moderna y adaptable construida con Tailwind CSS.

🛠️ Tecnologías Utilizadas

HTML5, CSS3, JavaScript (ES6+)

Tailwind CSS

Firebase (Firestore & Auth)

Google Gemini API

📝 Configuración Local

Para correr este proyecto localmente, debes configurar tus propias credenciales en el archivo index.html:

Agrega tu configuración de Firebase en la variable firebaseConfig.

Agrega tu API Key de Gemini en la función que realiza el fetch a generativelanguage.googleapis.com.
